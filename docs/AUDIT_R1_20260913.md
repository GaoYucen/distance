## Correctness changes

1. Landmark oversampling copies complete existing (u,v,d) triples. A batch without
   landmark triples is unchanged. This is not equivalent to farthest-point sampling
   or a guarantee of globally exact landmark ratios.
2. Dist2GNN forward consumes the GNN/MLP node-encoder outputs, rather than bypassing
   the encoder. Training recomputes encodings with gradients every batch; evaluation
   encodes once. The pairwise head is still a CROSS-ENCODER: do not transfer metric
   axioms to graph predictions. This new model is not checkpoint-compatible when
   gnn_input_dim and gnn_output_dim differ. Large-graph training is not optimized yet.
3. CrossEncoder uses r absolute-value dimensions and s signed dimensions, with an
   exact r+s dimension check. A plain nonnegative scalar head is included.
4. Validation is created ONLY from training OD groups. Opposite orientations remain
   together. Cross-split overlaps raise errors; test replication is disabled.
5. Directional auxiliary loss no longer divides a normalized embedding twice.

No clipping/nonnegativity guarantee is silently added to L1Tilde. Raw negative
predictions are counted. Scalar Softplus is an explicit different control model.

## Mathematical scope (direct derivation, not a novelty claim)

For a fixed shared-node embedding, L1Tilde(u,v) = ||z(v)-z(u)||_1 + h(v)-h(u),
where h is the sum of all signed coordinates. The antisymmetric component is an
exact potential difference; it sums to zero around every cycle. A unit directed
3-cycle has forward distance 1 and reverse distance 2, so it is a counterexample
to universal exact representability by this decoder, in any dimension.
A shared encoder does not force the signed decoder to be symmetric. Increasing
signed dimensions changes parameterization, not this scalar-potential restriction.
Nonnegativity in both directions requires |h(v)-h(u)| <= ||z(v)-z(u)||_1.

For paired squared loss, writing S=(d_uv+d_vu)/2 and A=(d_uv-d_vu)/2 gives
((P+Q-d_uv)^2+(P-Q-d_vu)^2)/2 = (P-S)^2+(Q-A)^2.
The diagnostic fits h using training A only. Its oracle-S error is NOT a learned
index result. Explained directional energy is NOT the fraction of queries and
is NOT the fraction of total model error. Under MRE, midpoint S is not generally
the optimal symmetric oracle: the paired optimum is min(d_uv,d_vu), giving
|d_uv-d_vu|/(2 max(d_uv,d_vu)). Both references are reported separately.

## Evidence and limits

reports/audit-r1-20260913/ contains actual runtime reports. Independent Dijkstra
must match the legacy matrix before neural experiments run. Integer edge lengths
are intentionally retained to reproduce the committed historical generator.
A three-seed small-graph pilot, when present, is exploratory and not a full city
benchmark. It uses a fixed train/validation/test split with both directions per OD;
validation MRE selects checkpoints and test is read only for final evaluation.
Efficiency claims require separate native exact baselines and CPU/GPU batch-size
experiments; R1 training times are not claims about online query latency.
