# R4C｜真实有向路网的未见 OD 验证协议 v1.0

冻结日期：2026-09-14。该协议在读取本轮测试成绩之前写入，不覆盖 R1–R4B。

## 目标

R4B 已表明固定 64 个 float32/节点时，多分量结构能突破单势差表达限制，但并未普遍优于 P64、共享对称几何或 IQE/MRN。R4C 不继续合成图调参，直接检查这些表示在真实原生有向路网的**未见 OD 对**上是否仍有效。

本阶段仍直接学习节点表，不加入 GNN。它验证“表示 + transductive pair generalization”，不是跨节点归纳泛化。

## 数据

只使用 R2 已独立核验并冻结的原生有向数据：

- Jinan_native_directed：8840 个 SCC 节点；100000 / 10000 / 10000 个无序训练/验证/测试 OD 组；OD 来自综述发布的济南轨迹工作负载后去重和跨集合隔离。文件 SHA-256 必须为 `22640a0e3fc7d5e35ae9b9d5dab6e3e172b787fd99c3b6ccac80809161b2053c`。
- Shenzhen_native_directed_uniform：11738 个 SCC 节点；40000 / 5000 / 5000 个无序训练/验证/测试 OD 组；OD 为固定种子均匀无序对，不冒充轨迹工作负载。文件 SHA-256 必须为 `8cede9cc3b77d22acf2877ee85e0d6fa34d05785bf05b1b4cc9a3f86566fc92c`。

每个无序组同时监督两个方向。正反向不得跨集合。测试标签只在每个种子的最佳验证状态冻结后读取。增加一个合成泄漏回归测试：改变测试标签不能改变训练历史、验证选择或所选状态。

## 固定 64-scalar 主比较

所有学习表示均为每节点 64 个 float32；训练和评测使用相同实际节点表预算。全局标量和固定尺度元数据另记。

1. L1：64维对称 L1。
2. T1：63维绝对值 + 1维势差，正部。
3. P64：64个纯势差取 max 与 0。
4. B2：2块，每块31维绝对值 + 1势差。
5. B4：4块，每块15维绝对值 + 1势差。
6. B8：8块，每块7维绝对值 + 1势差。
7. Shared-L1：56维共享 L1 + 8个势差取最大值。
8. MRN-L2：32维非平方 L2 + 32个势差最大值；这是 MRN 形式的节点表对照，不称原 RL 流程复现。
9. IQE-maxmean：作者 `torch-quasimetric@0365394` 的 IQE 区间公式，64维拆为 8×8；maxmean 的全局 alpha 可训练并单独计4字节。
10. IQE-sum：同样 8×8，sum reduction。

另外加入同样 64 个 float32/节点的非学习有向 landmark 对照：固定从训练 OD 涉及节点中随机选择 32 个 landmarks（RNG seed 20260914），每节点存 32 个“landmark→node”和32个“node→landmark”精确距离。报告：

- ALT32-LB = max(0, d(l,v)-d(l,u), d(u,l)-d(v,l))；
- ALT32-UB = min_l d(u,l)+d(l,v)。

两者共享同一个 64-scalar 索引。landmark 选择不看验证/测试标签；Dijkstra 构建时间单列。

## 优化

学习模型种子固定为 42/99/1234。float32。节点表用 CPU `Normal(0,0.1)` 的固定种子生成后移至 GPU；同一数据集和种子的十种解码器初始 64 维表必须逐字节相同。

- Adam，lr=0.01；不按方法单独调学习率。
- 1500 次参数更新；每次抽 8192 个无序训练组（不足则循环），同时使用正反方向。
- 固定按训练双向标签平均距离归一化；只用训练集计算一次初始输出均值校准因子，校准因子随后冻结。
- 优化目标：归一化距离 MSE；三个种子向量化但每个种子参数/Adam 状态独立，种子损失求和以等价于串行更新。
- 每25次更新计算完整验证集 MRE。每个种子仅按验证 MRE 保存最佳状态；并记录训练 MSE、验证 MRE 和最佳步数。
- 不因本轮结果增加更新数、修改损失或选择每城市不同 K。若明显未收敛，先报告为优化边界，再另立 R4C-v2。

## 最终评测

测试集只在 checkpoint 固定后使用。主指标：双向 MRE。并报告 MAE、P95/最大相对误差、训练距离下四分位对应的短距离 MRE、alpha=|d_uv-d_vu|/S >=20% 的高非对称 MRE、方向半差 RMSE、低估/高估/负预测比例。

多分量模型还报告每个分量的获胜比例与有效分量数。所有保存 checkpoint 用新的 CPU 进程和独立 NumPy 解码公式重放；逐查询预测差异和 MRE 差异都必须过阈值才可汇报。

## 判断规则

R4C 是已查看的 R2 数据上的新模型开发验证，不称最终独立确认集；尤其济南测试查询的标签在 R2/R3 分析中已经被查看过。它可以淘汰结构、估计真实量级，但后续投稿仍需新冻结确认数据/查询。

只有满足以下条件才进入 GNN/真实大图扩展：

- 至少一种**预先固定配置**在两个数据协议上都稳定优于 T1/L1，且不只是单个种子；
- 相对 P64、Shared-L1、MRN/IQE 至少存在清晰的精度—存储—解码复杂度理由，而不是每城后选不同赢家；
- 与 ALT32 同预算对照相比，若没有精度优势，则必须能解释其训练/查询/结构收益；否则优先转向有证书 landmark/字典压缩路线。

本轮不报告生产查询延迟，不把 GPU 批量拟合时间当查询时间。若主表示通过，再单立延迟与索引构建协议。
