# R4D｜有证书的双向 Landmark 势函数字典压缩 v1.0

冻结日期：2026-09-14。R4C 已显示同为 64 float32/节点时，ALT32-LB 在济南/深圳开发测试上分别为 5.9216%/5.5521% MRE，而从随机节点表学习的准度量明显更差。R4D 不据此修改 R4C，也不再训练神经模型；它验证 R4 理论提出的“结构化势函数字典压缩”是否能在真实有向路网上成立。

## 输入与教师

完全复用 R4C 已构建并冻结的 ALT32 索引，不重新选择 landmarks：32 个 landmarks，节点表含 32 个 `d(l,v)` 与 32 个 `d(v,l)`，共 64 float32/节点。

定义64个合法势函数：
- f_l(v)=d(l,v)
- g_l(v)=-d(v,l)

则教师下界
T(u,v)=max(0,max_l[f_l(v)-f_l(u)],max_l[g_l(v)-g_l(u)])
恰为 R4C 的 ALT32-LB。该教师已经由三角不等式保证不高估真实最短路。

## 结构化压缩

对 r=1,2,3,4,5,6，令每块包含 2^r 个教师势函数，并使用全部符号向量 σ∈{−1,+1}^r。每个块只保存 r+1 个生成坐标：h(v),z_1(v),...,z_r(v)，隐式势函数为 h(v)+σᵀz(v)。

每个 landmark 的 f_l 与 g_l 始终分配给一对相反符号。Landmark 按其冻结坐标的二维 Morton(Z-order)码排序后连续分组；若坐标并列，再按节点ID打破平局。该排序不使用验证/测试距离标签。

对每个块，先给每个教师势函数减去其跨节点均值（常数不影响势差），再用完整超立方体的 Walsh 一阶投影求最小二乘生成坐标。对于教师矩阵F（行对应符号，列对应节点）和A=[1,σ]，因为AᵀA=2^r I，生成坐标X=AᵀF/2^r。这一步无梯度训练、无测试选择。

预算为：
- r=1：32块×2 = 64 scalar/node。由于两个函数的完整一阶基等于全空间，该版本必须数值上复现 ALT32-LB。
- r=2：16块×3 = 48 scalar/node。
- r=3：8块×4 = 32 scalar/node。
- r=4：4块×5 = 20 scalar/node。
- r=5：2块×6 = 12 scalar/node。
- r=6：1块×7 = 7 scalar/node。

## 全局下界认证

Walsh 近似可能生成越过真实距离的势方向。因此每块必须在**全部原始有向边**上认证：计算 q_k(a,b)=||z_k(b)-z_k(a)||_1+h_k(b)-h_k(a)，令
c_k=max(1,max_{(a,b)∈E} q_k(a,b)/w(a,b))，并将该块全部生成坐标除以c_k。

认证后重新扫描全部有向边，要求 q_k(a,b)≤w(a,b)+1e-5·max(1,w(a,b))。由三角不等式，该块以及所有块的max对任意节点对均不高估真实最短路。记录每块c_k、最大认证余量和被缩放程度。

R4D 的科学指标不是“训练误差”，而是：每节点 scalar 数、教师势函数重构 RMSE、认证缩放、测试 MRE、短距离 MRE、高非对称 MRE、下界 gap，以及相对 ALT32-LB 的误差增加。

## 核验与边界

- r=1 必须在济南、深圳均与冻结 ALT32-LB 逐查询匹配（仅允许 float32/重算的数值误差），否则停止。
- 每个版本必须逐测试查询满足 prediction≤truth（容差1e-5相对+1e-3米绝对）；违反则停止，不汇报压缩成绩。
- R4D 读取的是 R4C 已查看的测试标签，仅用于开发压缩曲线，不是新的确认实验。
- 本轮不从结果后选一个预算称“最终模型”；完整 64/48/32/20/12/7 曲线都保留。
- 这个压缩算法是固定的 Morton 分组 + Walsh 一阶投影 + 边认证，不做结果驱动的聚类/重排。如果曲线有价值，后续再冻结一个“学习分组/优化分配”的独立协议。
- ALT32 的构建需要完整已知图上的单源最短路；该离线成本不隐去。当前目标是验证结构化压缩可能性，而不是宣称端到端 learned index 已完成。
